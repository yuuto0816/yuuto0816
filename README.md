##  自己紹介
- 🏆 **プロジェクト・コンテスト実績**: 学園グループ合同企業プロジェクトにて、ビッグデータを用いた分析・開発で最優秀賞をいただきました。また、AWS環境を用いたクラウド開発プロジェクトにもチームで挑戦しました。惜しくも入賞は逃しましたが最終審査まで進出し、インフラからアプリ開発までのフローを試行錯誤しながら一通り経験できたことは大きな学びになりました！
- 💼 **実務経験**: Datanaut / Urus にエンジニアとして業務委託で参画しています。AIチャットボット（LIFF）開発やコーポレートサイト制作などに携わっています。
- ⚡ **注力分野**: 現在は Python / TypeScript / Go を中心に勉強中です。幅広く対応できるようなエンジニアになりたいと考えています！
- 🌱 **学習スタイル**: 生成AIを使った「バイブコーディング」で開発を進めることが多いのですが、正直まだまだAIに頼ってしまう部分も多いです。そのため、AIが出力したコードをそのままにするのではなく、意図をしっかり読み解いて自分の力にできるよう必死に勉強中です！また、基礎的なコーディング力も高めたいと思い、paizaを使った学習なども日々進めています。
- 🎯 **目標**: 常に学ぶ姿勢を忘れず、開発に貢献できるフルスタックなエンジニアになれるよう、毎日コツコツ頑張ります！
